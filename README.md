# BioMind AI 🏥
Multimodal Clinical Report Simplifier & Intelligent Patient Assistant.

## Overview
BioMind AI bridges the healthcare communication gap by translating complex lab panels, blood work PDFs, and ECG wave metrics into clear, reassuring, and vernacular language.

## Key Features
- **Multimodal OCR & Parsing**: Extraction from diagnostic PDFs and image reports.
- **Biomarker Anomaly Triage**: Automated clinical range checks for markers including HbA1c, Fasting Blood Sugar, Troponin, and Cholesterol.
- **Vernacular Simplification**: Patient-friendly explanations supported in English, Bengali, and Hindi.
- **Safety Guardrails**: Built-in non-alarmist boundaries and medical disclaimer protocols.
